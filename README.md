# Adriaan M. Dimate Portfolio

3D vault-terminal portfolio for Adriaan M. Dimate, a software engineer, QA engineer, and aviation student.

## Stack

- TanStack Start
- React 19
- TypeScript
- Tailwind CSS 4
- Three.js with React Three Fiber

## Development

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the local development server
- `npm run build` creates the production build
- `npm run preview` previews the production build
- `npm run lint` runs ESLint

## Project Notes

- Main landing page: `src/routes/index.tsx`
- Shared portfolio data: `src/data/portfolio.ts`
- SSR entry wrapper: `src/server.ts`
